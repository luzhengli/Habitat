# 01 · Habitat Web 产品方案

> 最新交付要求：以用户已认可的 Air 原型高保真、像素级还原；后续界面/交互变化先改原型并获得用户确认。具体工作流与验收见 docs/10，功能已实现不能替代该门槛。

## 定位

**你的 Skills，一处看清，按项目使用。**

Habitat 是面向个人开发者/Skill 使用者与创作者的本地优先 Web 工作台。核心价值不是“一个软链接 GUI”，而是看懂来源、降低配置成本、解释生效范围，并让变更可预览、可追溯、可撤销。目标用户和价值判断来自本次讨论，尚未做独立用户研究。

用户已认可 Air 产品方向及视觉。新需求改变的是工程起点和产品形态，不是重新选择功能定位。

## 产品形态的最终约定

使用浏览器；同一电脑运行轻量本地服务。无需桌面壳，不做原生窗口、托盘或桌面打包。不需要账号才能浏览本地技能，也不默认上传技能正文、项目路径或凭据。

网页访问与文件作用域必须分开：浏览器展示数据，服务操作**服务所在机器**的授权目录。首发不支持“任意浏览器远程连接任何用户的电脑”。手机/其他电脑看远程服务器时只能看到服务器的文件，不能自动映射到用户 Mac。容器或服务器部署必须明确数据卷与边界，首发不默认提供。

首个实际文件系统验证平台可使用开发者的 macOS；这只是验证顺序，不再是 macOS 桌面产品。浏览器与操作系统支持矩阵独立记录。

## 五项核心工作

| 用户要做的事 | 产品结果 |
|---|---|
| 看懂已有 Skills | 用途、来源、内容变体、已知使用位置和扫描缺口 |
| 添加/收藏一项技能 | 默认只收录，不自动改动旧入口；保留来源关系 |
| 给项目配置 | 项目默认工具、草稿、变更预览、确认、真实回读 |
| 解释没生效 | 配置与发现分开；冲突、未知、条件与覆盖范围可解释 |
| 维护与撤销 | 有来源才可检查更新；差异与影响先展示；不覆盖个人修改 |

## 核心模型

“技能库”是统一认知入口，不等于物理 Store。外部内容可以仅引用和收录；只有用户决定托管/分发时才创建受管副本。无 Store 不妨碍只读查看。

用户管理关系至少区分：扫描发现（可能尚未持久收录）、仅收录、受管副本、来源不可用。当前 bootstrap 只做“扫描发现”，不能把它说成已持久收录。

来源、技能逻辑身份、版本内容、安装绑定分开：一个来源含多项技能，同名可以有不同内容，同一份内容有多个发现入口。名称、mtime 和文件路径都不能独自代表逻辑身份或“最新版”。

“仅收录”“创建托管副本”“停用原全局入口”是三种意图，不能串成隐藏副作用。首发彻底移除旧产品的强制迁移及“整笔恢复首次迁移”功能；日常事务撤销重新实现。

## 核心动线

首次使用：打开技能库 → 选择或输入要授权的本机来源 → 展示范围 → 只读扫描 → 用途/来源/缺口 → 按需收录。不能要求先清理所有重名才能进入。

使用技能：从库中点“使用”或从项目点“添加技能” → 选择项目/项目默认工具 → 需要时创建受管副本 → 草稿 → 服务端计划和预检 → 看变化 → 明确确认 → 事务回读 → 显示“已配置” → 可选实测发现。

维护：问题入口 → 原因和证据 → 影响范围 → 取消（无写入）或确认 → 执行/回读 → 历史记录 → 有条件撤销。

## 范围优先级

**MVP 必需**：真实只读来源/库/详情、收藏与用户索引、项目登记和默认工具、本地副本、项目配置计划/安全执行/回读、状态解释、日常事务记录与安全撤销、重启续接。先少量有证据的 Agent，不追求五种工具同时首发。

**MVP 后续**：GitHub 仓库来源、可靠版本更新与冲突 diff、更多 Agent 适配、开发目录跟随、技能集合。压缩包导入在路径/大小/链接/炸弹防护完成后再开放。

**明确不做**：旧仓库/旧数据库/旧恢复记录迁移，桌面壳，MCP/Rules/Agent 会话，公网多租户/云同步，账号与团队权限，公开技能市场，自动内容合并，自动 commit/push，任意 shell，Agent 启动接管。

## 状态承诺

- 已收录：本应用有持久来源引用，不说明已安装。
- 已配置：目标位置经过计划执行和回读，不说明 Agent 已发现。
- 预计可发现：版本化适配规则推断；明确条件和未知。
- 已确认发现：具体 Agent 版本、项目/工作目录、时间、证据匹配当前内容。历史适配测试不能代替当前机器检查。

工具共享物理入口时不能提供虚假的独立权限开关；工具可能从全局/父目录发现其他内容，项目“移除”不等于全局禁用。没有遍历全盘时，不声称已穷尽全部影响。指纹一致不代表内容安全。

## 价值验证

在不用开发者口头指导的情况下，用户能否找出一项技能的来源、解释已配置与已发现、配置一个项目并安全撤销。观察任务完成率、首次正确配置耗时、误影响和额外说明次数，不拿 DAU 或原型点击数替代产品价值。
