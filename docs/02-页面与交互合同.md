# 02 · Web 页面与交互合同

本文件是目标产品要求。`/demo` 是可点击的视觉示范；`apps/web` 尚未覆盖全部页面，不因此压缩最终能力。

## URL 和全局壳

正式路由：`/library`、`/library/:skillId`、`/projects`、`/projects/:projectId`、`/issues`、`/history`、`/settings`。`/` 重定向或映射 library；未识别路径给明确 404。技能详情可用嵌套路由或 URL query 表达，刷新和分享本机链接可恢复上下文；后退关闭抽屉不丢失列表筛选。

当前种子用普通链接和服务 SPA fallback，尚无完整路由/状态管理。M0 建立 React Router 或等价小型路由，不加入 SSR/全栈框架仅为了路由。远端链接一律新页、noopener，不在同源权限上下文加载任意 HTML。

主导航带文字：技能库、项目、需要处理、操作记录；设置在下方，最近项目可直接进入。浏览器工具栏不是应用自己的 UI，不画假窗口。移除原型中的原生标题栏占位和拖拽标记。

有 loading/empty/partial/permission-denied/disconnected/error。服务断连不是空库；只读历史可有“上次检查”标签，但不能当当前快照。能力来自 capabilities，未完成入口清楚禁用/说明，不静默切换 demo。

## 技能库

稳定主动作“扫描目录”“添加 Skill”。首次显示授权来源入口，不自动扫全盘。每个范围的访问结果单独展示，不用权限错误伪装 0 项。

卡片只展示名称、来源、用途、使用位置/必要状态和常显“使用”；默认两列。名称/描述可键盘打开详情。路径、指纹、文件树和版本进入抽屉。收藏不影响内容和配置。

分类、显示名和个人注释来自源声明或本应用索引，不改 SKILL.md。没有声明就标未提供，不从文件夹名称编造用途。

空库与搜索无结果不同：空库给来源入口，无结果给清除筛选。真实首次扫描数量动态，不能复制原型 9 项。

## 来源授权与添加

目标 UX：用户在“添加本地来源”里输入绝对路径、看到该路径含义、点击只读授权；服务验证可访问真实目录，保存 sourceId 后再允许扫描。启动 CLI 授权可以作为开发/高级用户入口，但不是最终唯一 UX。

浏览器拖入文件/`webkitdirectory` 只获得文件和相对路径；应作为“上传到受管快照”的独立来源，不自动当作原路径。不能把浏览器选中的目录句柄序列化为 Node 可以直接访问的绝对目录。showDirectoryPicker 不作为跨浏览器核心依赖。

注册来源只改应用索引，默认 read-only。授予项目写范围是后续单独明确动作。路径是服务本机路径；远程部署不得伪装成访问端电脑。

Git 来源单独提供下载/解析范围与费用/网络说明，先列出候选技能再选择，不默认安装整个仓库。私有认证延后，不从进程环境自动继承用户凭据。

## 详情抽屉

桌面约 548px，固定标题/底部操作，内容独立滚动。用途→使用位置→文件→版本；技术细节渐进展开。正文来自真实源或有标记的说明，脚本不执行、HTML 不透传，远程图片默认不自动加载以免泄露阅读行为。

只读文件 API 使用 source/skill/file ID 与受限相对路径，不暴露 `/read?path=/anything`。二进制、超大文件、不可读或改变的文件有明确状态。复制失败给可选中文本，不嵌套多个模态框。

## 项目页与草稿

添加项目只登记真实目录、身份及默认工具；不创建任何安装。写权限在明确动作中授权，不能把“添加项目”解释成能改目录里任何文件。

区分本项目配置和其他范围可见。后者只读显示 scope、来源、适配证据和可管理性。工具共享目录的副作用必须在确认层展示。

所有开关仅编辑草稿。预览来自后端 planId、版本摘要和预检结果。库内“使用”和项目内“添加”最终必须复用同一计划/执行链。

浏览器刷新/后退/切换页有未提交草稿：路由保护＋可恢复的 draftId；beforeunload 仅作尽力提醒，不依赖它阻止所有退出。关标签页不等于取消后端任务。明确取消 API 只能在服务认可安全点生效。

## 应用与发现

确认按钮只在完整预检通过后启用。提交带 planId、预览版本/hash 和幂等键。断网/超时后先按 operationId 查询，不重复发起施工。执行中显示真实阶段；完成后回读才标已配置；部分失败列出已执行、补偿和未知对象。

发现检查另行操作。未实现时显示未支持，不用 setTimeout 升级。需运行外部工具/网络时解释范围并明确请求授权；不运行任意 Skill 脚本。

## 诊断、更新与撤销

诊断使用“发生了什么→影响→建议→操作后果”。同名冲突展示两份内容与规则依据，无足够版本证据则没有赢家；不能比较 mtime 自动取新。

全局入口停用高风险，首发不实现一键全局修复；先只读解释。源重定位必须重新对比内容/身份，不能同名即替代。

更新只对可追溯 Git/版本来源启用；先 diff、本地改动和引用项目，再确认。普通用户默认固定快照；开发跟随模式后续独立实现。

历史记录保留意图、对象、结果、时间和可恢复性。撤销是后端事务：重新检查所有前置条件、当前引用和漂移，未知阻断。绝不应用前端 JSON 历史快照覆盖真实文件。旧“首次迁移整笔恢复”不进入新产品。

## Web 交互与验收

主入口不依赖 hover；键盘可达、可见焦点、模态焦点约束、Esc 安全关闭、关闭后恢复焦点。中文 IME 组合输入不触发快捷键。全局搜索可用 Cmd/Ctrl+K，但不得覆盖浏览器 tab 切换、地址栏和刷新；所有快捷键功能均有按钮。

窗口基准 1440×960、1280×820、960×640；小屏到 390px 做可读兜底，不等于推出手机管理产品。独立内容滚动、长路径换行/详情和可达确认按钮优先，不靠缩小正文字号塞满。

典型验收：授权来源→只读收录→详情→登记项目→托管→草稿→预检→取消（0写入）→确认→回读→刷新→历史→安全撤销。另测断连、多标签页竞争、源漂移、占用冲突、重启和无法回滚。
