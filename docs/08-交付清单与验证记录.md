## 关于网络/浏览器阻塞

没有安装前端依赖，所以未交付伪造的package-lock，也没有用本地替代转译器冒充Vite build。`npm start`和`start:fixture`零第三方依赖，直接可以运行本地服务/批准原型；`setup:web`在Codex实际联网环境安装官方包并保存精确版本。随后必须做build/typecheck/dev/浏览器验收。

浏览器失败发生在访问本地地址时，未开始原型交互。没有修改环境策略或移除服务安全边界绕过。tests/browser-smoke.py留作在可访问本地页面的环境重跑：它验证启动页与原Air，不是完整正式React功能测试。服务器要以`npm run start:fixture`运行。

MANIFEST.json与SHA256SUMS列出交付文件的相对路径、大小与SHA-256。`npm run verify:delivery`验证交付原件；开发后变更会导致差异，这是正常现象，不应该把该校验放进未来代码CI。
