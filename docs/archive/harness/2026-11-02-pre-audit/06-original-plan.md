# 06 · 实施计划与验收

当前执行阶段为 V0–V3 高保真还原，详见 docs/10、PLAN 和 tasks.json。M0–M3 保留为既有工程基线，以下 B0–M3 描述是原实施路线，不要重新 bootstrap；M4 的 WEB-15 视觉门槛已重新打开。功能测试与浏览器可用性不能替代用户认可的像素级还原。

先完成 V0 双侧截图/测量和差异盘点；必要修改先走 V1 原型候选与用户确认；按批准基线做 V2；V3 对照/回归及用户最终视觉验收通过后再关闭 M4。

## B0 — 本包已有，不能外推

已有：冻结Air原型、React参考源与截图，零依赖Node只读服务，启动页，授权目录样例，生产React/Vite源码种子，27项当前测试。无真实写操作、无标准解析、无生产DB、无依赖lockfile。

Vite源码依赖安装在当前环境受阻；浏览器本地访问也被当前环境策略阻断。两者均是M0实测事项，不能沿用历史19/11组原型记录。详见08。

## M0 — 建立真正可开发的 Web 基线

输入：本包根目录（可以是空Git新仓库），不是旧项目。

动作：核对基线，运行check；联网执行setup:web并锁精确依赖；编译apps/web；建立可复用的UI/query适配边界；逐步TSX化及明确剩余JS边界；为所有约定路径添加路由/刷新/404；保留原型为参考，不直接把模拟App作为生产。

退出：干净目录可依README安装/开发/构建/生产启动；有真实lockfile；build/typecheck/test通过；1440和960窗口截图；来源未授权状态真实；API失败不会出现seed数据。Web工具栏无Mac原生占位或drag依赖。引入的新依赖与Node版本记录。

不要完成M0后停止在规划：继续M1的授权来源真实列表切片。

## M1 — 只读技能库（首个完整产品切片）

动作：新增source/grant持久化与授权UI、schema v1、标准frontmatter解析、受限目录扫描、稳定技能身份、分页/搜索/收藏/详情、缺失/权限/变体/覆盖诊断。元数据与内容分离，远端图片/脚本不执行。

退出：用户不建Store即可授权一个本机来源并查看；浏览器刷新/服务重启可恢复索引；取消收录不删除源；目录/正文前后快照一致。多行YAML、中文、缺字段、目录名与声明名不一致、重复内容、同名异内容、超限/二进制/坏UTF-8、symlink、路径漂移都测试。

当前starter的“不跟随链接”只是一项保守策略。目标需要识别link类型与覆盖缺口，若支持受控symlink必须有边界测试；不能静默略去后却宣称完整。

## M2 — 项目配置与安全撤销（MVP的第二个真实闭环）

动作：受管Store安全验证、完整manifest与固定快照、非破坏性副本导入、项目登记/默认工具、批量draft、计划预检、确认、持久operation/step、锁、幂等、回读、日常撤销/重启恢复。先支持本地来源与少量有证据工具。

退出：库中使用与项目添加走同一backend；所有源和无关项目不变；创建/解除目标entry后回读；冲突预检0写入；中途失败只补偿自己创建且未漂移的对象；并发旧revision阻断；服务被杀后从journal准确解释/恢复；超时重试不重复施工；授权撤销阻断后续操作。

项目确认必须显示物理入口影响，共享入口不是独立权限；移除项目入口后其他scope可见仍清楚显示。已配置和实测发现分开。

## M3 — 诊断、来源与维护

先做只读诊断：缺源/坏链/同名变体/预期与实际差异/覆盖缺口。解释而非自动修复全局目录。Agent版本和证据缺失时unknown。

然后受限公开Git来源和更新：下载隔离、SSRF/大小/超时限制、完整包差异、用户修改保护、受影响项目与固定版本回退。私有仓库、上传压缩包、开发跟随和集合是独立后续任务，不绑死MVP发布日期。

实测发现是可选集成，有清晰收费/网络/认证和执行授权；不运行Skill代码来假装健康检查。没有runtime时保留已配置与预计状态，不能伪造“已发现”。

## M4 — Web 发布门槛

浏览器：Chromium及目标Safari分别实测；Firefox如未测标待支持。Mac先跑是测试平台，不制作桌面安装包。

操作：授权路径、移动/丢失、取消、重试、断连、并发、重启、升级schema v1→下一版、回滚与数据导出。服务关闭时页面明确离线；启动失败不换成公网地址。

安全：Host/Origin/Fetch-Metadata/会话/CSRF；没有任意读写/命令；CSP/外链/Markdown/XSS/SSRF；body/扫描限额；权限收敛；静态服务边界；输入验证；生产无debug/backdoor/demo数据混入。审计失败不能用force忽略。

视觉：所有核心状态同视口对比Air；长路径、中文、变体多条、空态/错误态；键盘/焦点/对比/IME/reduced-motion；弹窗底部可达。Web 适配先落原型并经用户确认，再以该版本的坐标、尺寸和状态对照；不得自行豁免偏差。

发布：干净clone＋lockfile可复现；文档描述Node/端口/路径授予/数据位置/备份/停服；未经用户指令不push、部署或发布npm。当前只提供本地启动交付，不生成危险公网compose。
