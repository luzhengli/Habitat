- 当前唯一获确认设计基线是 A0：`reference/air/Habitat-Air.html`、`reference/air/src/` 与 `design/01–12`。依据见 `design/prototype-baselines.md`。

- A0 与生产的 `tokens.css` 字节一致，图标数据字节一致；`styles.css` 大体沿用 A0，但生产页面没有输出许多对应结构，并由 `web.css` 与生产专用规则改变布局。视觉落差的主因是页面结构和状态缺失，不是换了一套颜色变量。
- 当前 A0 核心校验值：HTML `9359ed81…5814`；`App.jsx` `99f127e7…2023`；`Flows.jsx` `0f651e23…0cfc`；`styles.css` `f14fdf82…f890`；`tokens.css` `fa5722c5…2ce`。完整 PNG hash 已在本轮命令输出核查，原件未改。

分类：

- **D · 可直接还原**：A0 已明确且不会改变真实业务语义，可直接按现有基线恢复结构、组件、样式与交互。
- **C · 需原型候选并由用户确认**：Web 适配、真实能力冲突、A0 未覆盖状态或文案/信息层级变化。确认前不得接入生产。
- **F · 功能或环境缺口**：不能靠前端画面解决；保持禁用、未知或明确错误，待真实能力完成。其展示方式仍属于 C。

## 3. 全局壳与 Web 适配

生产壳只保留品牌、四个主导航、本地状态、设置、面包屑和一个“查看完整交互原型”链接（`apps/web/src/App.tsx:30–39`）。A0 的最近项目、问题计数、帮助、侧栏折叠、global search、command palette、项目面包屑、导航选中细节均缺失。

### D · 可直接还原

- A0 的侧栏分区、导航层级、最近项目列表、问题计数、底部本地状态、设置/帮助位置、topbar/面包屑结构。
- 侧栏收起、移动侧栏、modal/drawer 的焦点循环、Esc、焦点恢复、reduced-motion。
- A0 的 tokens、按钮、badge、notice、卡片、tab、drawer/modal 基础组件。生产 `UI.tsx` 已保留多数 primitive，但页面未充分使用。

### C · 需候选确认

- A0 默认 `shellMode='browser-preview'` 仍显示 `DESKTOP PREVIEW` 和 52px 原生标题栏留白，并保留 `data-tauri-drag-region`（`App.jsx:81–102`）。Web 是否保留同高留白、如何改文案和坐标必须在候选中确定。
- 原型的页面状态是组件内存；生产用 `/library[/id]`、`/projects[/id]`、`/issues`、`/history`、`/settings` 深链（`apps/web/src/App.tsx:11–27`，服务静态路由 `apps/server/app.mjs:144–160`）。浏览器后退/刷新、脏草稿离开、详情 URL、项目 URL 和 404 需用候选明确。
- 原型固定显示 `⌘K`；Web 应按平台显示或不显示。原型 Cmd/Ctrl+1–4 不能照搬，现合同也禁止抢浏览器标签页快捷键。
- “演示原型”、本地空间/本地服务、登录与上传边界等顶栏/侧栏文案要改为真实产品语义。

## 4. 技能库

生产库只提供搜索、收藏 checkbox、计数、两列卡片、50 项分页、部分范围 notice、空库/无结果和范围说明（`apps/web/src/App.tsx:42–47`）。卡片图标/颜色/来源文案被硬编码为 `file/blue/仅收录 · 本地来源`，没有 A0 的分类、托管、用量、更新、列表视图与排序层级（`:44`）。

### D · 可直接还原

- 页头、四个范围 tabs、分类筛选、排序、网格/列表切换、两列卡片、常显“使用”、收藏星、库底说明。
- 卡片的“名称/来源 → 一句话用途 → 使用项目/管理或更新状态 → 使用”层级。
- 空库、搜索无结果和长列表分页可以放进同一 A0 容器；生产已有真实状态逻辑，不需要改变其含义。

### C/F · 需候选或能力约束

- 生产模型没有 `category`、展示标题、语义 icon/color、显式 managed/update 字段（`apps/web/src/types.ts:1–6`）。UI 可保留 A0 布局，但未知值、目录名 fallback 和来源类型需候选；不能硬造分类或托管/更新。
- “已托管”在真实产品中不能仅由来源决定：固定 Store 快照与项目 binding 是事务结果，不能把只读收录误标托管。
- A0 的项目用量可由真实项目/exposure 聚合，但当前没有库级聚合 API；实现前需决定加载策略或服务合同。缺能力时展示未知/不展示的具体形态属 C。
- 部分扫描、授权为零、根目录变化、symlink 不跟随、名称变体等真实诊断没有 A0 状态，须候选。

## 5. 技能详情

生产 drawer 只有真实只读 notice、路径、fingerprint、文件清单和原始文本预览（`apps/web/src/App.tsx:51`）。A0 是完整四 tab 详情，含使用位置、用法示例、来源管理、环境要求、问题和底部动作（`reference/air/src/App.jsx:165–171`）。

### D · 可直接还原

- drawer 尺寸/头尾固定、hero、四 tab、overview/usage/files/versions 分区、路径折叠、文件树和安全文本预览容器。
- 收藏与“用于项目”底部动作、从 usage 跳项目、从问题跳诊断。
- 当前真实文件、fingerprint 与正文应进入 A0 的技术详情，不应把整篇原文作为默认首页。

### C/F · 需候选或能力约束

- `什么时候使用`、用法示例、版本、环境要求并无完整结构化 API；必须展示“来源声明/未解析/未知”，不能从 Markdown 自行编造。
- 二进制、超限、来源漂移、权限撤销、文件读取失败、长正文/长路径、无项目使用、项目 exposure 请求失败均是 A0 缺态。
- A0 的“内容版本”“有新版本”只适用于固定演示；真实 Git candidate、当前收录 commit、项目固定 snapshot 是不同层次，需候选区分。

## 6. 添加 Skill、扫描与来源授权

A0 将 GitHub、本地目录、zip、管理副本及立即配置项目放进一个三步 wizard（`Flows.jsx:4–31`）。生产把本地只读授权放在全局 modal（`apps/web/src/App.tsx:50`），把公开 GitHub 放在设置页的独立下载/候选/收录流程（`GitSources.tsx:5–13`）；zip 未实现。

### D · 可直接还原

- 三步进度、source cards、内容预览、选择卡、前后按钮、错误区、busy/disabled/focus 结构。
- “收录不自动启用”“选择项目后仍需预览确认”的信息层级。

### C/F · 必须先做候选

- **本地**：真实流程必须先输入绝对路径并明确只读授权，再扫描；原型的示例路径/模拟解析不成立。
- **GitHub**：真实流程是官方 API 联网授权 → 隔离下载 → 完整包差异候选 → 用户确认仅收录；不是输入 URL 后生成固定内容。
- **zip**：服务没有上传/解析能力，必须明确禁用和原因，不能留下可点击成功流。
- **托管副本**：生产只在明确项目计划执行时复制完整包到固定快照；没有“把来源整体保存成 Habitat 副本”的独立 API。该选项需删除、改义或禁用，均要用户确认。
- **同时配置项目**：必须经过服务端 plan/preflight/再次确认，不能随收录一步落地；wizard 如何衔接项目草稿需候选。
- 授权取消、网络失败、GitHub 配额、候选过大/链接/子模块、扫描部分完成、来源重复等缺失状态需候选。

## 7. 项目与项目草稿

生产已有项目登记、项目选择、真实 exposure、持久草稿、add/update/remove、plan/apply 和结果回读（`apps/web/src/Management.tsx:11–39`）。但界面缩成 picker、notice、binding rows、checkbox 列表和 draft bar，缺少 A0 项目卡/表格/tabs/chips/状态层级。

### D · 可直接还原

- 页头、项目卡选择器、workbench、项目标题/路径、问题条、配置表格、技能行、toggle、添加技能 modal、固定草稿栏和变更预览的几何结构。
- “配置完成不等于 Agent 发现”的脚注、脏草稿离开保护、空项目状态。

### C/F · 必须先做候选

- A0 的 `shared`（Codex/Pi/Cursor）与 Claude 两组开关是演示假设；真实 adapter 只有 Claude Code `.claude/skills`，`discovery:'unknown'`（`apps/server/operations.mjs:8、12–18、151–159`）。未支持组必须禁用并解释，不能伪造多工具启用。
- “模拟发现检查/模拟已发现”不能进入生产。真实检查只验证受管入口/快照身份，Agent 实测仍未知；对应按钮、badge 和完成反馈需候选。
- A0 的“其他范围可见/预计可见”依赖未授权用户级/父级范围推断。生产只可显示 `unknown`，不能列出假技能。
- 添加项目需要真实绝对目录和 `.claude/skills` 写授权；A0 的项目名、示例路径和入口组选项不适用。
- 项目授权撤销、revision/generation 冲突、入口占用、个人修改、预检权限、计划过期、执行中取消等 A0 缺态需候选。

## 8. 变更确认、执行和恢复

A0 只展示添加/移除计数和两类入口路径，点击后立即写演示状态（`App.jsx:194–199`）。生产计划包含真实 target/snapshot/manifest/影响说明，10 分钟过期；执行有 running、succeeded、rolled-back、recovery-required 与回读步骤（`Management.tsx:21–22、35–36`；`operations.mjs:52–150`）。

### D · 可直接还原

- A0 宽 modal、摘要计数、逐变更列表、继续编辑/确认的整体布局。
- 物理影响、源文件不移动、其他项目不变、Agent 发现未知等说明可放入原有 notice/technical details。

### C · 必须先做候选

- add/remove/replace/restore-version、target、snapshot、旧版保留、计划 hash/期限、预检失败如何分层展示。
- 执行中不可关闭、取消只在安全边界生效、成功回读、补偿成功、需要人工恢复、幂等重试和未知结果。
- 结果不能只分“成功/失败”；特别是 recovery-required 不能被普通错误 toast 淹没。

## 9. 需要处理、诊断与全局影响

生产 `Diagnostics.tsx:4–10` 只聚合授权扫描 diagnostic 和各项目受管 exposure，明确“不运行 Agent”；没有 A0 的问题/更新双 tab、对比详情或修复动作。服务也没有停用用户级入口、全局影响修复或任意来源重新定位 API。

### D · 可直接还原

- 页面标题、计数、问题/更新 tabs、问题卡、严重度、元信息、空态和底部真实性说明。
- 只读详情可沿用 A0 的宽 modal、比较卡和受影响项目列表。

### C/F · 必须先做候选

- A0 的“停用同名用户级入口”属于未授权全局写，不能实现；“重新定位来源”也没有对应安全 API。应改为只读证据、可执行的有界建议或禁用动作。
- 全局影响范围无法在未授权目录上枚举；受影响项目必须标“已登记范围内”与“范围外未知”。
- 真实 diagnostic code、根路径、扫描覆盖范围、入口/快照漂移、Agent 未实测如何呈现需候选。

## 10. 更新

A0 更新 modal 是固定版本、固定 diff、一次确认后所有关联项目一起更新（`Flows.jsx:53`）。真实能力是：联网检查来源 → 下载隔离 candidate → 比较完整包 → 确认收录为新来源版本；之后每个项目单独选择 update 并走 plan/apply（`GitSources.tsx:5–13`；`apps/server/app.mjs:70–97`）。

### D · 可直接还原

- 版本过渡、diff panel、受影响项目列表、撤销提示和宽 modal 的视觉结构。

### C/F · 必须先做候选

- 必须把“检查/下载候选/仅收录”和“项目切换固定版本”拆成真实阶段；不能用一个按钮假装拉取、覆盖和回读全部完成。
- GitHub 匿名配额、没有 diff、候选拒绝、旧来源保留、项目个人修改阻断、项目逐一更新、无项目使用、回退旧 snapshot 都需候选。

## 13. 响应式、可访问性和缺失状态

- A0 CSS 已含 1600、1199、999、800、570 等断点，PNG 11–12 覆盖 960×640；这些既有布局可 D 类还原。
- PNG 01–03 为 1440×960，04–10 为 1440×1000，不能直接混作同视口像素 diff。PNG 是不同交互时点：09/10 还包含前序演示操作生成的项目/历史，并非 `initialState()` 的独立初始页。
- 390px、长中文、长路径、多变体、IME、所有真实 disabled/loading/error/recovery 状态没有成套 PNG。虽然 A0 CSS 有窄屏规则，真实内容下的具体换行/滚动/底栏行为仍须候选和后续截图确认。
- A0 `Modal` 已实现 focus trap、Esc、焦点恢复和 body scroll lock（`reference/air/src/components/UI.jsx:9–45`）；生产复制了该 primitive。各新增候选状态必须继续验证 busy 时不可关闭、错误后焦点、返回原触发点及 reduced-motion。

## 14. HTML / 源码 / PNG 一致性结论

- **未发现可据此宣布 A0 冲突的源码差异**：HTML 内嵌 tokens/styles 与拆分 CSS 一致，主要页面/flow/model 结构可在自包含 bundle 中定位；12 张 PNG 的内容均能映射到源码可达状态。
